# Proyecto Vice · descargas

Launcher para Windows de un juego de Xbox Series con
[VIctory](https://github.com/Marvisak/VIctory). **No incluye archivos de ningún juego:**
necesitas tu propia copia.

## Descargar

Entra en **[la última versión](../../releases/latest)** y descarga **`Proyecto-Vice.zip`**
(uno solo, para NVIDIA y AMD).

1. **Descomprime el `.zip` entero** en una carpeta.
2. Abre `Proyecto Vice.exe` y elige tu gráfica: **NVIDIA** o **AMD** (la de tu PC sale marcada).
3. Elige la carpeta donde tienes el juego. Se crea un acceso directo en el escritorio y la
   primera vez precarga los shaders.

El motor es [cool_fox](https://github.com/DoubleGhosty/cool_fox) (CGBJ), con los ajustes de
cada gráfica. El launcher se actualiza solo desde aquí: no hace falta cuenta de GitHub.

Windows SmartScreen puede avisar porque el `.exe` no está firmado: «Más información →
Ejecutar de todas formas».
