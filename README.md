# Proyecto Vice · descargas

Launcher para Windows de un juego de Xbox Series con
[VIctory](https://github.com/Marvisak/VIctory). **No incluye archivos de ningún juego:**
necesitas tu propia copia.

## Descargar

Entra en **[la última versión](../../releases/latest)** y descarga el `.zip` de tu gráfica:

| Archivo | Para |
|---|---|
| `Proyecto-Vice-NVIDIA.zip` | gráficas NVIDIA (fork [hyphennn](https://github.com/fxceless/victory-fork)) |
| `Proyecto-Vice-AMD.zip` | gráficas AMD (fork [DexNom](https://github.com/DexNom/VIctory)) |
| `Proyecto-Vice-AvatarManz.zip` | la más rápida, pide 64 GB de RAM (fork [AvatarManz](https://github.com/avatarmanz/VIctory-7900XTX)) |

1. **Descomprime el `.zip` entero** en una carpeta.
2. Abre `Proyecto Vice <edición>.exe` y elige la carpeta donde tienes el juego.
3. Se crea un acceso directo en el escritorio. La primera vez precarga los shaders.

El launcher se actualiza solo desde aquí: no hace falta cuenta de GitHub.

Windows SmartScreen puede avisar porque el `.exe` no está firmado: «Más información →
Ejecutar de todas formas».

## Código fuente

Cada versión incluye `codigo-fuente.zip` con el código del launcher y, en `forks/`, de qué
commit de cada fork sale `victory.exe` y los cambios propios. Licencia GPL-3.0, como VIctory.
